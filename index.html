Data Processing & Sync Pipeline

Meridian Wealth OS uses an automated Python ETL pipeline to ingest, clean, and synchronize disparate broker holding reports into a unified multi-currency database:

  • Raw Sources: CSV / Excel holdings imports, broker downloads, or browser drag-and-drop.
  • ETL Master Script: scripts/build_portfolio_csv.py reconciles holdings, matches tags from data/tags.csv, incorporates date overrides from data/holding_date_overrides.csv, and outputs canonical data/holdings.csv.
  • Live Price Feed: scripts/live_prices.py queries AMFI API (Mutual Funds), BSE API (REITs/InvITs), and Yahoo Finance (USD/INR and US equities) in parallel.
  • Flask Server: app.py runs on dedicated Port 5151, exposing REST endpoints for holdings, transaction activity, and the AI committee.

Key Platform Features & Math Formulas

Multi-Lot Symbol Aggregation:

Consolidates multiple buy lots of the same scrip (e.g. AAPL across 3 lots, ICICIBANK across 4 lots) into a parent row with weighted average cost: Weighted Avg Price = Σ(Qty × Price) / Σ(Qty).

Tax Status & Holding Days:

Calculates elapsed days from each lot's genuine purchase date. Assets held ≥ 365 days automatically receive the LTCG badge (taxed at 12.5% vs STCG slab/20%).

Multi-Currency Display (INR / USD / DUAL):

Dynamic FX conversion engine allows seamless switching between INR (₹), native USD ($), and Dual Mode (domestic assets in INR, US holdings in USD).
